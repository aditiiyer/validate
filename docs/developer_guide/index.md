# Developer Guide

For contributors and maintainers. It explains how VALIDATE is put together, how to extend
it, and how to test, document and release it.

| Page | Read it to |
|---|---|
| {doc}`architecture` | See how the modules fit together and how data flows through a run. |
| {doc}`settings_and_logs` | Understand `analysis.yaml`, `task_log.yaml` and when results are cleared. |
| {doc}`extending` | Add a derived structure, an AI model or a dosimetric model. |
| {doc}`contributing` | Set up a development install, run the tests, build these docs, release. |
