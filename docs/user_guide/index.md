# User Guide

Everything here is done in the VALIDATE window. You don't need to write any code.

**New to VALIDATE?** Start with {doc}`getting_started`, then take the {doc}`gui_tour`.
Then pick the tutorial that matches the data you have:

| You have | Tutorial |
|---|---|
| Scans, and want AI contours of the structures a model needs | {doc}`tutorials/segment_cohort` |
| Scans and dose, and want an NTCP from AI-derived structures plus clinical factors | {doc}`tutorials/ai_seg_to_ntcp` |
| Scans, dose and your own contours of the structures | {doc}`tutorials/existing_structures` |
| A table of dose metrics already computed elsewhere | {doc}`tutorials/precomputed_predictors` |
